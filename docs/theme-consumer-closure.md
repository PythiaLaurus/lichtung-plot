## Storage, Scope And Capture Identity

- Plot stores an optional shared complete appearance; Canvas stores its complete
  root. An explicit Plot replaces all inherited components. Facets use their
  owning Plot, Matrix keeps its Plot scope, and root-owned composition/guide
  chrome uses Canvas.
- `ResolvedTheme` holds that one appearance beside operation-local font/query
  state and Canvas compositing context. Font discovery/caches do not become
  construction fields or appearance equality.
- Measured child inputs include component address, exact panel/origin,
  constraints, immutable source configuration, the complete resolved appearance,
  scale policy and relevant feedback. Appearance comparison includes all mark,
  annotation, axis, guide, composition and eighteen text-role values.
- Heatmap's intrinsic fast path separately retains final scale/contrast/surface/
  backdrop/cell-mark/cell-annotation dependencies. Selected alpha and padding do
  not reuse stale role measurements.
- Pre-font continuous and Histogram preparation receives its complete owner.
  Shared domains install before final guide labels and contrast/font selection.
  The continuous mapping reprojects semantic stops, never a local projected
  gradient. Supplemental instructions remain immutable and optional.
- Selected marks, label placements, guides and brackets retain final operands;
  canonical geometry is frozen once. In particular bracket tick height and label
  gap have no backend default reconstruction. Replay performs no theme merge or
  scientific re-preparation.
