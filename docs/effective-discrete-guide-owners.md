# Effective discrete guide owners

Private Plot/Canvas operation state now selects effective composition before
producer key preparation, exact union and final section font census. This builds
on the single descriptor, projection and measured owner in the preceding guide
evidence. Public setters/root export remain the later atomic API cutover.

## Effective policy and transport

Plot retains its own selection (Combined default) and an optional parent-scoped
replacement. Marker erasure preserves both. Standalone and facets consume the
owning Plot's effective selection. Canvas retains an optional selection, applies
its Combined default or explicit replacement to every Shared contributor, and
leaves the stored public-source child selection unchanged. PerPlot consumes each
Plot's own selection; Canvas's value is inactive there. Hidden still suppresses
guide semantics before font work while scientific color coordination remains.

`PreparedInteriorInputs::prepare_discrete_guides` now consumes that effective
value instead of unconditionally constructing Combined. The former private
Separate dead-code expectation is removed. All typed section construction,
exact explanatory-key compatibility and final immutable transport remain shared
by the two policies. There is no conflict gate on stored child enum values.

Composed child inputs and content-height inputs retain the effective value beside
the already consumed complete descriptor. This closes the immediate policy
operand; explicit consumed guide/allocation/feedback dependency records and
ancestor stability still belong to the next integration leaf.

## Parent domains and fonts

Facet Separate ordering uses each consumed field's own full parent group/hue
domain, not first occupied-cell order or a representative pair. Only fields with
an actual section add ordering identities; an unpainted subject/group domain
does not become guide work. Entry membership still comes from actual prepared
contributions, so parent ordering never creates an absent key.

Canvas Separate union preserves declared row-major contribution order and each
prepared contributor's source order. Its global color domain, which includes
Hidden marks, is not a visible-entry ordering authority. Combined retains its
existing observed-pair/hue ordering path. Literal and supplemental domains retain
their typed ordering and source label context.

The existing descriptor preorder census consumes the final effective sections
before canonical fonts. Shared typography is Canvas-owned; key paints remain
source-owned, including the originating Plot's neutral label RGB. Measurement,
font requirements and selected output retain the original Shared/Plot/facet slot.

Combined layer-only authority test to the changed owner-policy contract. With

* Shared default Combined yields one Treatment section and three point entries.
* Shared Separate yields Treatment then literal `series`, still three point
  entries and the same original source census.

  output; each expected string is retained once and in its semantic order.
* Stored child selections remain unchanged. Returning the same Canvas to PerPlot
  ignores its Separate override and prepares mixed Separate/Combined local guides.

right facet's **red**. The complete parent scientific order is independently
**blue/red/green**, and that is the retained section order. Actual complete-root
preflight succeeds. Aliasing blue/green to one displayed identity refuses before
font discovery, preserving the original collision boundary in the richer owner.

The existing actual Bar and Interaction producer-binding tests additionally
compare the production effective-policy preparation with the directly specified
Separate descriptors. The unconfigured independent Interaction now exercises
actual root preflight under its private Separate selection: unsupported

No library tests are added or moved; two existing owner tests migrate in place,
and the two producer tests are strengthened. Discovery remains **671 tests,
