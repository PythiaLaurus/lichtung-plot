# Coordinated Scientific Numeric Guides

Heatmap and Beeswarm guide preparation now retains the effective optional numeric
policy and a complete `FormattedSet`: canonical raw member bits, resolved common
precision and actual source strings. The required members are lo, strictly
interior center, hi, or one scientific constant. Missing keys remain separate.
Private color-label attachments use the existing ContinuousColor capability;
their public exposure belongs to the atomic numeric API cutover.

## Final Owner Before Fonts

Continuous contributors compare complete normalized policies, including default
Automatic versus explicit configuration, before any font work. Compatible
contributors merge their scientific domains under existing scale/exact-domain
rules, then format one final required set. Fixed or exhausted adaptive collisions
are Data presentation errors; arithmetic/storage failures remain fatal.

Canvas applies only continuous-guide suppression before preparing Shared/Hidden
children. A locally ambiguous guide therefore cannot reject a required final
Shared set before that set exists. Hidden guides contribute no numeric text or
affix glyph requirements. Scientific source rows, fills, stops and selected
contrast roles keep their existing preparation owners.

Final Shared installation copies the retained numeric set; it does not format a
child again or independently select another precision. Measured guide feedback
retains/observes the complete policy, member bits and resolved precision alongside
the existing geometry/text inputs. The prepared continuous descriptor is shared
immutably through the containing-frame descriptor.

## Canonical Local And Natural Inputs

Each family supplies one descriptor from its prepared marks for both natural
preference and actual local measurement. This removes the historical Heatmap
`[0,2,1]` and Beeswarm `[1,0]`/constant `[1]` reindexing adapters. Numeric labels
now preserve canonical semantic order and their actual relationship to the
gradient endpoints and center. Actual full label strings enter the existing
canonical font/unit census, including literal affixes.

The Beeswarm percentage fixture verifies exact display scaling and a literal `%`
while retaining every raw row and the expected mark colors after a final Shared
domain replacement. Formatting does not alter color interpolation or coordinates.
