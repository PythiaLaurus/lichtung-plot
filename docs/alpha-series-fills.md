# Explicit Alpha For Scientific Areas And Bands

Source baseline: `f619519`. Density areas, Line bands and Regression bands bring
the completed fill-consumer census to **10 of 15 families**.

- Density retains an independent area operand for every actual group/hue curve,
  including selected owning facet fields. Line resolves its independent series
  fill only for an actually complete configured band. Absent bands still validate
  the binding schema. Trajectory and LinePath gain no fill capability.
- Regression validates a Single fill binding independently of its observation and
  fit-stroke bindings, and consumes its byte only for a configured fitted band.
  OLS input, predictions and pointwise intervals remain unchanged.
- Each final area/band replaces only fill alpha, retaining the independently
  selected outline. Intrinsic requirements use the same per-unit final style as
  selected geometry and automatic painted-ink expansion. Scientific ranges,
  generated vertices and source order remain independent of transparency.
