# Factorized Discrete Sections

The sole prepared descriptor now constructs both Combined and Separate sections.
Separate has typed GroupStyle, Joint, HueColor, literal-domain and supplemental-
series identities. Section classes have stable semantic order; values retain
source order and exact raw identity. Titles and labels resolve before fonts;
nonempty ambiguous headings and colliding displayed identities within a section
refuse. Equal labels in differently titled sections remain valid.

## Projection And Truthfulness

Every actual source pair is projected and checked. Configured independent
Interaction styles produce group and hue sections. Group projection changes only
hue-bound RGB to the owning Plot legend-label RGB, preserving each component's
original alpha, fixed/exact paints, outlines, widths, radii and actual group styles.
Hue projection keeps original paints/geometry, substituting Circle/Solid only in
explicit InteractionGroup style slots. Text alpha is never installed in a key.
Same-field/group-only Joint, literal and layer keys retain complete explanations;
hue-only/row-hue keys retain their actual glyph with a projected color explanation.

Complete/projected explanation masks participate in exact key equality. Mapped
versus constant outlines cannot merge as the same hue explanation merely because
their current RGBA and widths match. Source records retain original binding
provenance, actual projection and only the consumed group-neutral RGB. Projection
requires a complete source key and consistent neutral operands; an already
projected key cannot become another source for factorization.

Unsupported independent pairs refuse before fonts, including unconfigured
Interaction; no representative pair or invented group style rescues them. Hidden
guide construction skips that guide-only work. Scientific/style preparation still
precedes it. Same raw group/hue field collapses to one complete Joint section even
without a group-style mapping. Different raw fields never collapse through aliases.

The sparse three-pair Interaction contract yields two group plus two hue entries,
three original primary/pair sources and six actual projection occurrences. It
asserts original point/connector alpha, exact fixed outlines, producer styles,
neutral RGB from transparent label paint, unambiguous headings, legal equal labels
across sections, unsupported refusal and same-field collapse. The real Bar source
also checks mapped/fixed DataOutline slot neutralization and projected-mask refusal
at identical visible paint.

Literal endpoint/Regression keys retain exact glyphs and label text. Row-hue keys
remain point-only and filter locally unobserved palette values. Labeled Line layers
form the final literal `series` section; their categorical source label context is
preserved separately from verbatim point annotations and exact alpha instructions.
The existing public Line-only PointLayer attachment remains its actual gate.

title independently of layer-only contributor order; Separate unions typed

occurrences retain their records and checked counts. Errors identify the raw
identity, contributing source and mismatched component/mask. Source-role names
remain provenance, not a hidden family discriminator in key equality.
