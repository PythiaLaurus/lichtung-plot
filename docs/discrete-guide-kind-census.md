sources for every one of the seventeen Legend families. Previously several
capable fixtures were unkeyed and therefore exercised only absence. It retains
the original all-kind scientific/domain validation, one capture/Null/backend
lifecycle, source-drop frozen replay, SVG outlining and PNG checks.

Before fonts, the production preparation path is exercised under both Combined
and Separate. An independently listed component table asserts authoritative
presence/absence and exact section, entry, point, line, fill and source counts.
The census uses the normal continuous-aware preparation boundary, not direct
discrete dispatch for Heatmap/Beeswarm. Their prepared discrete absence is
explicit, while their actual selected continuous output remains covered by the
same lifecycle contract.

both policies. Same-field Interaction stays Joint; hue-only and positioned series
stay truthful color sections; row-hue paths contain no connector key. These
fixtures do not claim to be independent-pair factorization evidence.
