# Public Section Composition Acceptance

The section-guide implementation has focused public acceptance evidence for the
remaining unsupported-factorization, alias, layer and Shared-compatibility paths.
This closes the discrete-section implementation umbrella. It does not execute the
integrated scientific-foundation or release/timing/RSS gate.

## Public Contract Matrix

`tests/categorical/grouping.rs` adds one public unsupported-pair contract over
Line, Density, unconfigured Interaction, Marginal and native Matrix. Both a single
observed pair and three observed pairs use an exact map assigning the same gray
RGB to both hue values. Neither small membership nor identical colors licenses
factorization:

- Combined accepts all five producers' complete pair semantics.
- Separate rejects all five with the unsupported-factorization diagnostic even
  with an unavailable requested font.
- Shared Separate rejects the four Canvas-admitted families under the same absent
  font; Matrix remains native/local rather than acquiring a Canvas route.
- Plot Hidden and Canvas Hidden skip guide factorization and unpaintable/ambiguous
  guide titles.
- Hidden still rejects an incomplete exact hue map before the absent-font error,
  both locally and in admitted Canvas children.

The test performs 64 real preflight operations across those cases. It adds no
backend stub or public capability escape. Existing same-name contracts now cover
both composition policies for all six pair-capable families, including LinePath.
Equal source columns collapse; a differing row still reports the original source
row. The rendered Line contract preserves the one same-field title/identity under
both policies. Different raw fields with equal values and aliases still retain
their Combined pair text and reject unsupported Separate decomposition.

The three-category Matrix name fixture now explicitly requests 1200 by 800 for
its semantic acceptance check. Its former omitted-size operation encountered the
bounded root feedback-cycle refusal, rather than a same-field semantic error.
There is no automatic-dimension golden, root-search change or production sizing
repair in this leaf. Existing native Matrix automatic/width/exact contracts remain
owned by the earlier all-mode closure evidence.

## Shared Explanations And Complete Keys

`tests/interactions/styles.rs` adds a public Shared Separate figure with distinct
raw group fields `cohort` and `model`, and one common `shade` field. Children store
different composition choices. The Canvas policy produces exactly these ordered
explanations:

1. cohort: Control, Semantic Agent;
2. model: Control, Semantic Agent;
3. shade: red, blue.

The guide has six lines, four circles and two triangles; all eight source markers
remain present, for fourteen point symbols including guide keys. The common hue
section merges once. Combined refuses incompatible primary domains. Aliasing the
two distinct group fields to one nonempty title refuses ambiguity. Existing Shared
exact-color and custom outline-alpha refusals now exercise both policies, including
semantic refusal ahead of an unavailable font.

`tests/composition/canvases.rs` adds actual Scatter/Trajectory cross-family sharing
under both policies. A complete Theme supplies radius six, alpha 91 and absent
point outlines. Two observations in each family yield four marks and one merged
point-only key. Every actual circle has the requested radius and alpha. An
unpaintable trajectory group value introduces no group-guide text. Changing only
the trajectory radius to seven refuses complete-key compatibility ahead of an
absent font. Producer identity is not itself a merge barrier, and equal RGB is
not sufficient for a merge.

The earlier producer-binding proof remains the independent equal-paint/different-
explanation witness: mapped and fixed Bar outlines with identical RGBA/geometry
cannot merge into the same projected explanation. This leaf does not replace that
test with visible-color comparison.

## Supplemental Identity And Labels

`tests/lines/numeric_layers.rs` strengthens three existing public contracts:

- One labeled layer remains distinct from its two verbatim point annotations in
  Combined and Separate. Its unkeyed literal label `selected_coordinates` remains
  verbatim; a categorical source context resolves it to `Chosen sample` through
  Labels. Both cases preserve two data points and one layer key.
- A categorical identity and a layer identity resolving to `Chosen sample` refuse
  within Combined, but coexist in the distinct `cohort` and `series` sections of
  Separate. Equal text does not alias their source identities.
- Exact duplicate layer styles merge under both policies. A duplicate layer label
  with a different RGB, alpha or radius refuses; actual source points are not
  deduplicated by guide-key merging.
