# Scoped discrete measurement reuse

The existing sectioned measured owner now reuses exact assigned-guide outcomes
within the canonical root font operation. This completes the bounded measurement
checkpoint after `stacked-discrete-sections.md`. Runtime semantic preparation
continues selecting Combined until parent/effective-policy and public cutovers.

## One owner and one measured payload

`ResolvedTheme` owns an operation-local `GuideMeasurements` cache beside its
prepared font environment and text-query cache. Parent-scoped theme copies share
those three operational stores together. Fresh root resolution creates fresh
stores; no global or cross-operation guide cache is introduced. Operational
stores do not participate in appearance or descriptor equality.

The measurement key retains:

* Original semantic guide address and diagnostic attempt ordinal.
* Canonical assigned width and optional finite height, including None/Some.
* Orientation and consumed normal/compact variant.
* The complete prepared descriptor by value: composition, sections/boundaries,
  identities, strings, keys/explanations, source occurrences and neutral RGB.
* Complete owning LegendTheme and both guide text roles, including literal font
  stack identity, paint, size, weight and original leading bits.

These are the actual local measurement operands. Source Plot mark styles and
coordinated scientific domains are already resolved in the descriptor. Unrelated
surface/axis/annotation roles cannot create a local measurement dependency.
Ancestor child/height dependencies remain the following integration checkpoint;
this local cache does not claim to replace those keys.

Lookup compares complete values after canonical constraint conversion. Equal
descriptor values in different Arc allocations can reuse a plan. A successful
normal result, or its typed fit miss, can also serve compact when every entry
allocation was proven unchanged. Active compact changes still evaluate fresh
dependent labels/capacities through the same core. Fatal errors are not cached
or converted into fit alternatives.

Legend retains immutable Arc metrics and the one immutable section layout;
returning a cache hit clones only retained handles and canonical scalar inputs.
It does not clone section/label vectors, reconstruct glyphs, shape text or redo
flow. Fit diagnostics use checked fallible string copying. Cache growth uses
fallible reservation, without accounting fees, a new quota or an eviction-based
semantic fallback.

The smaller discrete handle means Canvas's large continuous guide is now boxed
once when it enters the shared measured-guide union. The temporary inline-size
Clippy exceptions are removed. Continuous guide representation/semantics are
otherwise unchanged. The existing selected-metadata-poisoning test mutates a
private copy-on-write metrics value; frozen calls remain independent of it.

## Existing attempt limits remain authoritative

Measurement lookup does not claim or reset placement attempts. Containing owners
continue their existing eight automatic/two explicit outside attempts per root
round; sections do not become owners. Rejected ancestors and child feedback
replay retain the same attempt accounting. In particular, the 32 observation
counters in `orchestrator/measurements.rs` are not a guide-flow budget.

## Evidence

`scoped_section_measurements_reuse_values_and_invalidate_consumed_inputs` uses the
actual sparse Interaction descriptor from the section measurement fixtures:

* Equal-value descriptors with different Arc allocations reuse the exact layout.
* An ineffective compact request shares that normal plan and does no shaping.
* Direct uncached evaluation retains a different measured payload but produces
  byte-identical SVG in the same operation.
* Changing the raw group field while aliasing it to identical visible text keeps
  SVG/dimensions equal but invalidates measurement reuse.
* A consumed label-paint change invalidates the plan and changes actual SVG while
  keeping dimensions equal. An unrelated panel-surface change preserves the hit.
* Different owner, orientation, finite-height presence or a single incoming width
  quantum each invalidates the measured plan. Finite heights retain capacities.
* Repeated infeasible assignments preserve the exact typed diagnostic/owner.
