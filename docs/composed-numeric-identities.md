# Composed Numeric Presentation Identity

Root-local child and measured-height keys now retain the complete normalized
numeric policies for both axes, continuous guides, cell values, estimate labels
and total shelves, together with the scientific linear/Log10 scale. Equality
compares complete values and affix bytes, never Arc identity or current text width.
The compact shared `NumericInputs` record is a key, not a second formatter.

`ComposedInputs` still copies complete axis specs and retains exact ticks,
intervals, provenance, domains, scoped category domains, visibility and root
request. The new numeric record supplies policy comparison for child probes and
selected-child reuse. Canvas height keys additionally retain it alongside assigned
width, effective domains, resolved Forest domain, own/parent insets and scope.

Prepared scientific members remain immutable for each root/cell owner. Ordinary
axis and Waterfall window selections additionally depend on the existing consumed
domain and feedback keys. Shared continuous installation finishes before census
and allocation; it cannot silently replace a live child source after its key was
recorded. Canvas range groups preserve independent panel formats. Fixed facets
check complete effective generated formats and ordinary/power operand context
before merging numeric domains; raw category signatures keep their separate role.

Heatmap intrinsic keys now retain and compare the complete value presentation,
including original members, selected precision and labels. Equal positive labels
under different negative-zero policies therefore miss at the same color domain.
Existing complete contrast, surface, cell-mark and annotation geometry inputs
remain part of that key.

Numeric value and continuous-guide feedback records occurrence signs separately
from spatial number observations, whose zero normalization is intentional for
geometry. Normalizing displayed negative zero cannot erase a scientific occurrence
sign from the selected presentation identity.
