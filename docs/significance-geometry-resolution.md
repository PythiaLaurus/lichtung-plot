# Effective Significance Geometry

## One Selected Appearance

`ResolvedTheme::effective_significance` retains the selected complete text role,
actual exact-override provenance, exact-or-theme label gap and complete annotation
geometry. An absent exact style remains absent and selects the theme-owned gap.
An explicit style replaces only size, weight and gap. All other geometry resolves
against the final selected significance-label em.

Bars, horizontal bars, attached Coefficient text, pairwise comparisons and the
font census consume this value. Attached safety reserves add the exact gap, extra
clearance and measured extent before one upward boundary. Grouped attached text
uses the same selected category centers as marks. Comparison panel containment
still includes actual half-stroke plus one quantum.

Spatial geometry is resolved only when consumed. Font preparation and plots
without comparisons do not resolve unused tick-height/level/panel geometry into
spatial bounds.

## Planner To Canonical Capture

Each planned comparison owns its final `BracketStyle` beside the deferred label
plan and selected geometry. Tick height is a required retained operand. The shared
backend validator passes it to canonical construction and rejects malformed,
nonfinite or negative operands. SVG, geometry observation, Null validation and
frozen canonical capture therefore use the same tick height.

Final rendering reads the retained style, never the mutable caller or a preset.
The separate annotation-style array and its reconstruction fallback are removed.
The backend global geometry record and the accessor that supplied an exact
`SignificanceMarkStyle::DEFAULT` for absence are deleted. Test replay identity
also includes tick height; changing it after capture is rejected.
