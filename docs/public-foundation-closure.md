# Public Foundation Precedence Closure

The complete Theme/component/font/scale cutover and heading instructions are
current. This closure exercises those public inputs across the external crate
boundary. It adds no alternate representation, renderer, compatibility API or
library unit tests.

## Public Construction And Actual Owners

The existing Canvas owner integration now constructs Theme through all eight
public component arguments. Distinct root-title, composition-header, TextPanel
title and body roles retain independently supplied stack, paint, CSS size, weight
and leading. Parsed SVG checks the actual selected roles and complete wrapped
body words, with the exact 12px × 1.5 leading requirement. Custom Canvas/panel
surfaces and root accents coexist with a completely replaced Science child. An
unused fixed qualitative palette does not recolor unkeyed marks.

The facet owner integration supplies a distinct public facet-header role and
checks both complete strip labels and their actual font/paint. Default omission,
explicit replacement and cross-operation isolation retain their existing owners.
Typed custom stacks explicitly append the preset's ordered fallback preferences
after the requested generic; an unmatched host generic is not assumed to supply
a family or silently repaired by the renderer.
