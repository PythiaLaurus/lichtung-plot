# Discrete Producer Bindings

Every contributing producer now creates its complete key together with explicit
encoding, RGB bindings, style bindings and source layer-label context. These are
retained in the final section descriptor's actual source occurrences, alongside
producer/address/ordinal and Complete projection. There is no second retained
source-entry list, role-string map, glyph-to-domain inference or alternate renderer.

`legend/source.rs` owns the closed private vocabulary and transient source-key
assembly. Only actual key roles have bindings: primary/mandatory-strip/supplemental
points; the eight consumed fill roles; and series/path/density/Interaction,
summary and Regression-fit lines. Raw-overlay/flier points and neutral connectors
remain outside their producers' guide grammar. Absent components/outline slots
retain no dormant binding. Producers use the same mark-role materializers as
their selected marks.

RGB mapping retains raw field/value identity. Fixed point outlines stay fixed;
DataOutlineTheme's selected mapped/fixed choice determines fill-outline binding,
even when the two choices produce identical RGBA and width. Endpoint and explicit
PointLayer paint have ExactElement provenance. Regression/reference/sign/accent
paint stays role-owned rather than becoming a categorical mapping. Only explicitly
configured Interaction styles bind shape/pattern to raw group identity. The
source validator checks component presence, encoding/identity/context consistency,
raw mapped identities and that producer restriction before fonts. Layer display
resolution consumes its retained source context rather than guessing from a
parent's final title.

Combined compatibility still compares exact visible keys, not producer/role tags.
The actual Bar contract demonstrates equal mapped/fixed-outline keys merging to
one entry with two source occurrences, while complete descriptor identity retains
their different provenance for later reuse/validation.

Prepared Bar and sampled-distribution sources filter palette/position domains by
actual retained bars/groups before creating keys. Global palette indices and empty
dodge slots are unchanged. The scientific observed-color accessor uses the same
membership and now supplies Canvas's one pre-font color-domain owner; the duplicate
point/path-named family extraction and obsolete carrier names are removed.
Hidden/group-only Interaction mark colors remain independent of entry visibility.

## Verification

**22 focused library tests and 14 existing integration tests pass.** Coverage
includes actual equal-RGB mapped/fixed Bar provenance, sparse configured Interaction
shape/pattern and exact point-outline ratios/alphas, all 25 kinds through one native
lifecycle, six actual child-cache contracts, Line layers, Regression line/band,
Density, literal endpoints, native Matrix, Hidden palette capacity and Shared
primary/layer authority. Existing sampled/supplied strip parity now also rejects a
fabricated key from an unobserved parent hue containing an unavailable scalar.

External checks cover observed sparse traces, complete glyph/outline Shared
conflicts before fonts, same-field collapse, omitted-series dodge slots, hidden
group-color coordination, exact Shared pairs, layer collisions, signed bars and
the continuous Shared boundary. A zero-match exploratory authority filter is
excluded; the actual both-source-orders contract passes.

Strict all-target Clippy, formatting, whitespace and current-source retirement
searches pass. Discovery remains **671 library tests, including 17 ignored**. Two
producer-level binding tests replace the lower-level
`mapped_and_fixed_outlines_keep_fill_and_stroke_alpha_independent` and
`point_roles_share_the_exact_ratio_and_apply_outline_policy_once` inventories.
The meaningful independent alpha, outline geometry and invalid-ratio contracts
are exercised through the actual producer keys; remaining width/normalized-absence
tests stay separate. No full suite or scene-golden repin was used.

Separate projection, explanation masks and section union remain the next semantic
leaf. This checkpoint retains truthful source operands; it does not claim that
Separate layout or public selection is available.
