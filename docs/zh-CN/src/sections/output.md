## 输出、字体与错误

[English](../en/index.html#output)

### 一次渲染，多次发布

`.svg` 使用本次操作持有的已安装字体字节，将所有文字转为轮廓并检查不再有 text 元素。
接收者不需要字体，但可见字形路径不是可选择、可搜索的文本，且依赖生成环境字体。
`.svg_preserve_text` 发布包含可选择、可搜索、可编辑文字及有序回退声明的规范 SVG，
不嵌入字体数据，查看者需要合适字体。两种形式来自同一个冻结 Output；再次发布不会
重复统计、字体发现、回调或布局。

PNG 将轮廓场景栅格化。`.png` 默认使用 300 DPI／平衡压缩，并写入物理密度元数据；
`.png_preview` 使用规范 CSS 像素尺寸、平衡压缩，不写密度元数据。
`.png_with_options` 在每次调用独立选择精确的 PngSizing／PngCompression。
无论栅格尺寸如何，Output::width／height 始终报告规范 CSS 尺寸。

### 尺寸与目的地

Plot／Canvas 默认按内容推导尺寸。`width(600)` 指定完整外部 CSS 宽度并推导高度；
`max_width(600)` 限制完整自然宽度，不拉伸较小图形。`size(600,400)` 请求精确尺寸对。
每次都替换完整的旧请求，因此 size(...).max_width(...) 会清除显式高度。
零尺寸在预检时拒绝，尺寸约束不启用未请求的文本缩小或省略。嵌入图的尺寸属于 Canvas。

SVG 调用追加 `.svg`，PNG 调用追加 `.png`；只有原生最终文件名已经以完整后缀结尾
（ASCII 大小写不敏感）时才不追加。已有文字不被替换：`plot.v1` 变为 `plot.v1.svg`，
传给 svg 的 `plot.png` 变为 `plot.png.svg`，`.plot` 变为 `.plot.svg`。
后缀补全不要求 UTF-8，发生在转换完成之后。父目录必须已存在；目录目的地，包括指向
目录的符号链接，都会失败。示例 CLI 默认使用当前工作目录；若另行指定可选输出目录，
辅助代码会为方便使用而创建该目录。

每个文件都先在相邻暂存路径完成，再原子发布。预检／转换失败会保留已有目的文件，
并清理暂存残留。链式调用不是多个文件的统一事务，各次发布彼此独立。

### 字体策略与失败

每个使用中的文本角色有独立的类型化字体栈。默认顺序为 Noto Sans、Noto Sans CJK SC、
DejaVu Sans、Liberation Sans、Arial、sans-serif。缺少可见字形或匹配候选集为空会报错，
不能据此选择无关字体。工具不会下载或捆绑字体；被替换且未使用的旧角色不会要求旧字体。

构造函数验证与数据无关的不变量；准备阶段尽可能在字体工作前检查科学对齐、域及
适用性。实际几何与文本适配使用选定字体和约束。算术、分配、I/O、字体及适配错误
向外传播，不会转到另一个绘图器或减少内容重试。确定性依赖相同来源、配置、依赖版本
和字体环境，不保证跨版本、操作系统或字体安装的字节一致性。

PDF 及报告生成仍由应用负责。[图库](#gallery)会在适用时链接同一示例的轮廓和保留
文字输出，不维护完整图形的黄金哈希或自动面板坐标。
